Mocap reconstruction pilot: export and measurement

The original private lab workspace supplies assets, the verified six GEM-X recoveries, the existing MotionBricks environment and the generated reconstruction inputs. Set MOTION_LAB_WORKSPACE to that directory when running these scripts from the public checkout. Personal reference videos, weights and exact internal request arrays are intentionally absent from this repository.

1. In the original MotionBricks environment, run `upstream/.venv/Scripts/python.exe tools/mocap_rebuild_soma.py`. The generation/preparation tool creates evaluation/mocap-rebuild/<source>/<raw|cleaned|single|window>/soma-frames.npz and source-metadata.json. Inputs retain the native77 SOMA hierarchy; the official MotionBricks SOMA engine reads its required30-joint subset. No G1 conversion is involved. `--prepare-only` creates the two non-neural controls; `--reassemble-cached` rebuilds neural playback from retained responses without making new model calls.
2. Run python tools/run_rebuild_exports.py raw cleaned single window in the original workspace. Or run Blender4.5 LTS individually: blender --background --python tools/retarget_mocap_rebuild.py -- ukemi raw. Bake raw before cleaned because they deliberately share the exact raw-first-pose vertical calibration. Sources: ukemi, technical-standup, gorilla-front, sumo-stomp, source-094553, h3-dance.
3. Each export is independently reloaded and validated with node tools/validate_mocap_rebuild.mjs ukemi:raw. Node dependencies are the original workspace tools/review/node_modules (Three0.160, gltf-validator). Geometry-only Node validation substitutes image objects; actual browser texture/render checks are separate.
4. python tools/build_mocap_rebuild_catalog.py publishes only all24 validated GLBs, compact provenance/validation reports and compact neural traces. It does not publish source footage, frames, checkpoints or exact private arrays. --allow-partial is for local UI development only.

The adapter retains original C08 geometry, rig and rest fingers. It uses one scalar floor calibration per clip, with raw/cleaned sharing the exact scalar; it never adds a per-frame vertical floor clamp. Later hovering or penetration remains visible. The body is not physically balanced and no hand/foot contact IK is applied. Valid GLB structure and zero loop seam do not imply acceptable animation.

`tools/audit_mocap_rebuild_generation.py` checks the private cached conditioning/response arrays, exact FP32 context chains, selected targets, playback deduplication and engineered loop boundaries. `tools/audit_mocap_rebuild.py` checks the public 24-artifact matrix, hashes, reports, loop measurements and publication size. Neither accepts an animation on visual or physical grounds.

Measurements use shortest-arc local quaternion differences at30Hz. Angular step/acceleration statistics exclude the engineered neutral holds, while segment-boundary neighborhoods and first/last velocity are reported separately. Joint export parity checks every saved key, segment lengths are sampled120Hz and complete original skin vertices8Hz. Floor measurements are sampled diagnostics, not continuous collision proofs. The generated methods freely reinterpret source timing, so lower acceleration is not proof of source fidelity.

All12 neural versions use96 genuine MotionBricks SOMA FP32 calls in total. They begin/end with authored12-frame canonical-neutral holds; the return to that neutral is a genuine neural segment. Coincident first samples are removed at joins, while complete raw model responses remain private. Only the final tiny numerical endpoint residual is snapped to the requested neutral and disclosed in the trace. Raw and cleaned controls retain full source timing and are not closed loops. The neural gorilla exercise deliberately excludes unreliable frames174-238; both full-length controls remain available.

Individual loop closure is separate from cross-performance pose identity. The twelve C08 neutral poses have joint positions agreeing within0.5micrometres, but wrist orientations differ by up to1.67degrees between performances. A production state library still needs a shared wrist calibration or transition blending; see research/mocap-rebuild-common-default.json.
