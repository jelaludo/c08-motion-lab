The demo blends idle → walk → jog → sprint and back, keeping the step cycles aligned. The controller uses jump-start → airborne → landing, and sit-enter → seated idle → sit-exit. Random mode shuffles 14 curated routines, completes jump/sitting phases, and blends back to neutral idle for 1.6 seconds between routines. Roll remains available manually because this set has no matched recovery for it. These transitions are conventional animation playback.

Limits and comparison notes

Retargeted human movement still needs review on C08’s broad armor. Ground placement is baked; planted hand/foot locking and collision physics are not implemented. A floating seated pose needs a chair. Direction changes and action interruptions remain basic. These 20 clips establish a consistent comparison set, not a finished character controller.

Our research tab includes MotionBricks-generated clips and separate video-derived clips. Its Continuous button blends baked playback; it does not run the MotionBricks AI in the browser.

Animations by Quaternius, Universal Animation Library 1 Standard, CC0. C08 model by jelaludo. Hands use an authored relaxed cup with inward finger curl and thumb opposition. No paid-tier assets used.
