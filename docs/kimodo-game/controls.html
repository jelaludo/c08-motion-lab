    03 / INVENTORY AUDIT

    What are we missing?

    “Present” means a candidate exists in our catalog, not that it has passed visual review. Existing clips can be unfinished, unconnected or inappropriate for a held state. Gaps below distinguish new animation work from controller, camera and metadata work.

    Recommended next round

    1. Measure and wire the existing set: gait phase, active transition windows, action events and world displacement. Test responsiveness before adding more variants.
    2. Build the highest-value game states: first reuse the earlier Fight guard, footwork and backward-roll sources; derive guard enter/hold/exit, distinct evasions/rolls and fall/landing recoveries. Generate only what those sources cannot supply.
    3. Validate connections on both bodies: target-facing circles, sprint-stop-turn, carry placement and ceiling-safe crouch. Keep motions with review evidence.
    4. Choose the game’s combat scope: weapon aiming/reloads and cover need props, layers and gameplay systems. Swimming, vehicles and magic can wait for a level that needs them.

    No generation jobs are started by this study. It defines the next test plan.
