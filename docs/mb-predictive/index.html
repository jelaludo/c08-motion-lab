What am I comparing?

Left: an actual MotionBricks-G1 prediction, retargeted to C08. Right: non-neural position/joint interpolation with quaternion interpolation, using matching source endpoints and duration. Its sliding is intentional: joint interpolation does not synthesize a gait.

Both use the same C08 adapter; only the neural output supplies predicted contact labels. This is a controlled illustration of in-betweening, not a quality benchmark against an authored animation system. Teal/amber ghosts show G1 conditioning skeletons scaled for display, not C08 keyframes.

Inputs are classified by source: original numerical poses, CC0 Quaternius poses, your own captures, or our original-input MotionBricks outputs. Restricted bundled-sample experiments are available only in the local evaluation view. The model chooses duration within an allowed range; endpoint correction is enabled. Longer paths use the previous prediction’s last four poses as context. Target reach does not guarantee collision avoidance, balance or correct support contacts.
