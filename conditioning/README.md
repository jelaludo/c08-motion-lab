# Original G1 conditioning poses

C08 is the user's original model. G1 is the numerical rig expected by the installed MotionBricks model; it is a motion interface, not a replacement character design. A pose contains 36 values: pelvis XYZ in metres, pelvis quaternion XYZW, and 29 hinge angles in radians. Four recent poses give the model recent motion; one to four target poses describe the intended arrival and, when consecutive moving poses are supplied, arrival velocity.

We authored six original base postures in `evaluation/c08-worker/round2/original-g1-poses.json`: neutral, crouch, deep crouch, right-hand reach, two-hand reach and hands overhead. Sixteen gallery tests use these poses with new root placements/headings and no bundled sample motion. No training or new neural weights were needed.

## Make a pose in Blender

1. Open `g1-pose-authoring.blend` in the installed Blender 4.5.15.
2. Select `G1_CONTROLS`. Open Object Properties > Custom Properties and edit the 29 angle sliders. Their bounds come from the reference XML. Blender displays angle properties using its angle UI; the stored values are radians.
3. Move or rotate `PELVIS_G1` for the floating root. G1 source axes are Z up and +X forward. Blue marks anatomical left; amber marks right.
4. The Blender text `Apply_Original_Pose.py` can load one of the six starting postures. Change `pose_name`, then run that text. The library is stored in the text `ORIGINAL_G1_POSES.json`.
5. Save a separate `.blend` after editing. Export its numeric pose using the command below.

From `G:\Dev\MotionBricks`:

```powershell
& .\tools\blender-4.5.15-windows-x64\blender.exe -b .\conditioning\g1-pose-authoring.blend --python-exit-code 1 --python .\tools\export_g1_pose.py -- --name my_pose --output .\conditioning\my-pose.json
```

Replace the input `.blend` with your saved copy. The exporter writes the exact joint order and rejects angles outside the recorded limits. Saving a pose does not itself generate animation; these values become the context or target arrays for the generation wrapper. An action such as stand → crouch → stand is generated by making successive target requests and carrying forward the last four retained output poses.

The proxy uses original simple rods and joint markers, not Unitree visual meshes. It is for authoring the model's inputs. C08's original shell/rig stays in its own files and receives motion through the adapter.

## Verification

`neutral-export.json` is a tested export. `validation-report.json` compares all 30 body transforms against Newton: maximum position discrepancy about 0.0012 mm and maximum orientation discrepancy below 0.00001 degrees. This verifies the pose-authoring interface, not balance or collision safety.
